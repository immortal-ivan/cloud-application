# Cloud Application

Учебный проект по дисциплине «Управление работами и разработка ПО облачных систем».

## Структура проекта

```
cloud-app/
├── app/
│   ├── __init__.py
│   ├── config.py
│   └── main.py
├── .gitignore
├── requirements.txt
└── README.md
```

## Установка и запуск

```bash
# Создать виртуальное окружение
python -m venv .venv

# Активировать (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Установить зависимости
pip install -r requirements.txt

# Запустить приложение
python -m uvicorn app.main:app --reload
```

## Эндпоинты

| Адрес     | Описание                        |

| /         | Основная информация о приложении |
| /status   | Состояние приложения            |
| /about    | Информация о стеке              |
| /course   | Информация о дисциплине (ЛР №2) |

## Запуск с явными сетевыми параметрами

```bash
# Локально на порту 8000
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

# На всех интерфейсах
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# На другом порту (ЛР №3)
python -m uvicorn app.main:app --host 127.0.0.1 --port 8080 --reload
```

## Лабораторные работы

- **ЛР №1** — Подготовка среды, создание минимального приложения
- **ЛР №2** — Создание серверного приложения с несколькими обработчиками
- **ЛР №3** — Исследование сетевых параметров (IP, порты, 127.0.0.1 vs 0.0.0.0)

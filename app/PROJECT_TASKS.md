# Cloud Application

## Этап развития

Фильтрация и контроль состояния облачных сервисов.

## Требования

REQ-01 — API должно поддерживать получение списка сервисов по состоянию.
REQ-02 — Для поля status допускаются только значения: running, maintenance, stopped.
REQ-03 — При отсутствии параметра фильтрации API возвращает полный список сервисов.
REQ-04 — Документация API должна отражать новую возможность фильтрации и допустимые значения status.
REQ-05 — При передаче недопустимого значения status API возвращает ошибку 422.

## Definition of Done

Задача считается завершённой, если:
- необходимые изменения реализованы
- приложение запускается без ошибок
- существующая функциональность не нарушена
- новый функционал проверен
- код размещён в соответствующем модуле
- документация обновлена, если изменение затрагивает API
- результат соответствует критериям задачи
